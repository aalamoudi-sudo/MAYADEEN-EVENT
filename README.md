# Mayadeen Event World — Private Client Review

هذه حزمة مراجعة عميل خاصة ثابتة للمنصات الخمس، وليست تشغيلًا حيًا أو موافقة هندسية أو HSE أو افتتاحًا.

- انشر محتوى `frontend/` فقط من جذر نطاق HTTPS خاص ومحمي بالوصول.
- طبّق إعدادات `hosting/`، ووجّه مسارات SPA غير الموجودة إلى `/index.html`.
- استخدم `model/gltf-binary` لملفات `.glb`.
- لا تخلط ملفات من مراجعتين؛ الاسترجاع يتم باستبدال مجلد الإصدار كاملًا.
- لا توصل بوابة IoT أو شبكة خارجية بهذه الحزمة.
